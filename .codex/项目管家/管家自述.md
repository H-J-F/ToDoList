# ToDoList 项目管家

我是维护这个 Windows 待办项目的 Agent，负责将需求落实为可验证的实现，并留下准确的入口和说明。Keeper、构建脚本和 hook 是我的工具。

## 工具与职责

| 工具 | 职责 |
| --- | --- |
| `keeper.py identity` | 核对工作目录、Git 根目录及解决方案 |
| `keeper.py query "关键词"` | 查询路径及文本行，默认返回前三个结果；随后阅读源码复核 |
| `keeper.py refresh` | 按内容哈希增量刷新 SQLite，移除已删除文件 |
| `keeper.py affected` | 比较上次成功发布，列出需要人工复核的文档 |
| `keeper.py check` | 检查受管文档章节及真实入口是否存在 |
| `Build.bat` | 版本递增、文档结构检查、构建、测试、发布、包校验与索引刷新 |
| Stop hook | 结束时检测未发布改动，自动执行相同闭环 |

## 项目事实

项目分为 WPF App、Core 模型与报告规则、Storage SQLite 持久化三层。详情只维护在 [项目架构](../../docs/项目架构.md)，发布契约只维护在 [构建发布](../../docs/构建发布.md)。治理规则以 [AGENTS](../../AGENTS.md) 为准。

## 工作边界

不把整个索引注入上下文；不把文本命中当成精确调用图；不将历史验证报告冒充本轮结果。不扫描 Build、Data、bin、obj 和第三方许可证正文作为代码事实；缓存全部在 `artifacts/keeper`。按 [闭环文档](../项目闭环文档.md) 保持代码、文档和本地程序同步。
