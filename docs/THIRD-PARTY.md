# 开源依赖与许可

- [WPF UI 4.3.0](https://github.com/lepoco/wpfui/releases/tag/4.3.0)：FluentWindow、TitleBar、控件资源、ContentDialog、Snackbar、SymbolIcon，MIT。完整许可见 `licenses/WPF-UI.txt`。
- [Fluent System Icons](https://github.com/microsoft/fluentui-system-icons)：由 WPF UI 分发的功能图标字体，MIT。完整许可见 `licenses/Fluent-System-Icons.txt`。
- [Microsoft.Data.Sqlite 10.0.10](https://github.com/dotnet/efcore)：SQLite ADO.NET 驱动，MIT。
- [SQLitePCLRaw 3.0.5](https://github.com/ericsink/SQLitePCL.raw)：SQLite 原生桥接与运行库，Apache-2.0；SQLite 本身为 public domain。
- xUnit、Microsoft.NET.Test.Sdk：仅用于开发测试，不随桌面应用分发。

本应用的浅蓝任务清单图标为项目内自绘矢量，不属于 WPF UI 商标或应用图标。功能性小图标统一使用库的 SymbolIcon。
