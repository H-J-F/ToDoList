## WPF 实际窗口基准

自包含发布版本、10 万条任务，启动至首批控件完成布局约 **1.15 秒**；30 次页签切换 P95 约 **40.3 毫秒**。连续加载和滚动测试中最多缓存 **2,000 条任务**，实际任务控件约 **5 个**；缓存内容约 **1.9 MB**，进程工作集从约 **207 MiB** 到 **216 MiB**。

上述数值是本机测量，不是所有硬件、冷文件缓存或超长富文本情况下的承诺。原始窗口报告：`artifacts/benchmarks/rows-100000/ui-results.json`；发布版界面检查：`artifacts/publish-check/screenshots/ui-smoke-results.json`。测试程序可按 README 中的命令重复运行。
