## 平台边界

Windows 11 Snap Layout、多显示器跨屏与位置恢复、物理显示器 DPI 切换、真实鼠标拖动和边缘缩放尚未在对应环境中人工验收。窗口按钮和程序性缩放已运行验证；原生行为交由 FluentWindow／TitleBar。资源管理器图标缓存显示、屏幕阅读器完整流程仍需目标机器人工检查。

v1 首次升级需要备份和重建索引，其耗时不纳入已升级 v2 库的日常启动基准。备份保存在 Data/Backup；迁移失败回滚。
