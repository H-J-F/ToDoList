# 微云账号与云同步

## 职责

提供本地优先的个人云存档：默认游客空间，微信登录微云后在独立账号空间离线使用、自动同步、手动上传与下载、比较并处理冲突。最终应用使用原生 .NET 与 Windows DPAPI，不要求终端用户配置服务器、密钥、Token 或安装开发验证工具。

登录提示为“扫码授权即同意使用当前微云空间保存 ToDoList 云存档。”实际微信身份确认、微云协议和文件权限授权由用户在官方页面完成。应用默认直连用户微云，资源占用用户自己的空间。

## 契约

### 账号与授权

- 账号入口位于左侧设置按钮正上方，两者同为 40 DIP 整行透明按钮、12 DIP 水平内边距、20 DIP 图标区域与 10 DIP 图文间距。未登录使用灰色 WPF UI PersonCircle20 图标及灰色“未登录”；已有授权显示可信缓存昵称与 20 DIP 圆形头像，资料缺失时回退“已授权”和默认图标。长昵称省略并显示完整悬停提示；账号短标识只在面板内显示。
- 登录、授权说明、同步状态、上传下载、自动同步、冲突处理、本地笔记复制与退出统一位于独立的 440 DIP 右侧“账号与同步”面板，不再位于外观设置中。两个面板互斥，重复点击入口、关闭按钮、外部点击或 Escape 可收起；下拉框优先处理 Escape。隐藏窗口时收起两个面板并结束动画。
- 2026-10-13 查询官方 tools/list：14 项工具均未提供昵称、头像查询；实际 token 响应只有 access_token、token_type、expires_in、scope、refresh_token。OAuth 元数据没有 userinfo_endpoint，权限限 files:read/write/manage。补充资料来自同一内嵌登录会话的官方微云网页，不是新增 OAuth 权限或官方资料 API。
- 默认 WPF UI FluentWindow 承载 Microsoft.Web.WebView2 1.0.4258.31，使用每次登录隔离的 InPrivate 会话。关闭、取消和超时取消授权、释放浏览器和 loopback；成功关闭登录窗口并刷新主界面。系统 WebView2 Runtime 不打包、不自动安装；初始化失败、页面异常可重试或主动使用系统浏览器。
- 授权后仅在 https://www.weiyun.com/act/openclaw 主页面读取 syncData 中白名单资料字段（nick_name、https_head_img_url、main_dir_key、root_dir_key 及页面规范化别名）。至少一个空间标识必须精确匹配原生接口确认的 RootKey；缺失或不匹配不使用资料。资料阶段最多 10 秒，不影响已完成授权。头像只下载官方 CDN HTTPS 地址，无 bearer、Cookie 或自动重定向，限制 2 MiB 和 4096×4096，解码后规范为 64 像素 PNG。读取脚本不导出网页 Cookie，不开放主机对象或 Web 消息接口。
- 昵称、头像缓存独立于 token 和数据库，按本地 Data 指纹／账号空间指纹 DPAPI 保护；刷新 token 不丢资料，退出回游客清除界面资料但保留账号缓存。新账号无缓存时不沿用旧账号资料。官网网页结构变化、资料读取或图片失败使用默认显示；真实微信资料是否取得以真实扫码报告为准。
- 系统浏览器授权完成后尝试恢复主窗口，保留可见窗口的当前最大化状态；成功注册关联时 loopback 回调提供不含 code／state／token 的 todolist-desktop://activate 按钮。普通运行按当前用户注册到当前可执行文件；内嵌登录、隔离验证、显式 --data-dir 或注册失败不提供协议按钮，避免激活用户其他安装。不接受返回 URI 中的其他路径、查询或 fragment；仅通过既有单实例机制激活，不重新执行授权。浏览器可能要求确认，Windows 可能限制前台切换。
- “导入本地笔记到当前账号”保持完整原标题（包括 100 字标题），不截断、不追加“本地副本”；模块、任务、富文本、状态、历史、回收站和笔记设置保持原样。导入保留笔记身份；同 ID 使用共同导入基线合并，没有可靠基线时并列保留不同版本；不同 ID 同名独立，内部文件名必要时避重，不修改展示标题。源笔记和已经导入的历史标题不会批量改写。
- OAuth 元数据的 issuer 与授权、注册、token 地址必须与固定微云官方地址一致，支持 S256 和无客户端密钥。系统浏览器由用户授权；本机 TCP 只监听 127.0.0.1 的系统分配端口，不使用需要 HTTP.sys URL ACL 配置的 HTTP 监听。
- 回调限制 GET、路径、Host、随机 state、头部长度和接收时间，不接受重复 query 字段；超时、拒绝及取消都释放监听端口。凭证交换与刷新只发往固定 HTTPS token 地址。
- 账号工作区标识是官方 token 所绑定空间 key 的 SHA256 指纹，token 不是账号身份。已验证两个真实微信账号空间不同，同一 token 刷新后保持空间；初始化前检查已有凭证的空间身份，身份变化停止同步。
- 游客 Data 保持原位置；账号工作区在 Data/Accounts/<空间指纹>，登录后不自动复制游客数据。全局外观、窗口位置和按工作区记忆的导航保存在本机游客设置；笔记内设置参与同步。
- 授权从扫码成功起有效 14 天，凭证中的 AuthorizedAt 固定不随 Token 刷新或重启延长；旧凭证首次读取写入一次起算时间。第 14 天边界停止云端请求，提示重新扫码，保留原账号本地工作区；服务端提前撤销授权仍需重新登录。
- 凭证、活动选择及资料缓存位于程序根目录 Auth，采用当前 Windows 用户 DPAPI；内嵌登录的每次临时浏览器目录位于 Auth/Browser。显式 --data-dir 时二者均位于指定 Data/Auth，隔离运行不读取正式旧缓存。正常运行迁移 LocalAppData/ToDoList/Cloud/<当前Data路径指纹> 中的已知文件，新位置已有数据优先；验证成功后按来源哈希清理旧文件，持久迁移记录防止退出后再次恢复旧活动选择。失败保留来源并提示，不回退 C 盘写入。活动选择只包含空间指纹；退出去除选择并返回游客，不删除账号数据库与云端历史。
- 账号本地加载独立于网络授权与云目录初始化。启动先选活动账号本地工作区，凭证损坏、授权过期、刷新失败及离线不切回游客。新登录通过根目录查询确认身份后先准备、提交本地工作区，再初始化云目录；初始化失败保留本地空间并暂停自动请求。身份未确认或用户取消不猜测新账号；本地准备或活动选择落盘失败保持原工作区。
- 切换前处理待保存编辑，取消并等待旧账号请求、隔离迟到结果；先准备账号缓存和笔记，再提交切换。准备或活动选择落盘失败保留原工作区。

### 文件与版本

- 每个空间的文件统一限定于 ToDoList 父目录；创建、复用 Data/Sync 的远端目录 ID，不操作其他文件。同名父目录不唯一或服务端自动改名时停止。
- 文件 API 使用 bearer 凭证，下载客户端不设置默认 bearer/cookies，不跟随下载重定向；下载只接受当前应用目录列出的文件与 HTTPS 地址。
- 云协议 v2：Data 保存 `device-<设备GUID>-<20位代次>-<SHA256>.db`，Sync 保存唯一 `protocol-v2-<SHA256>.db`。文件是真实 SQLite DB，CloudPayload 表保存 gzip 压缩的完整领域数据、删除标记、冲突及因果上下文；协议 DB 包含迁移种子和旧文件来源清单。云协议与本地笔记 v5 格式独立，不直接上传运行中的 db/wal/shm。对象不可变，同名只接受字节一致，不写共享 latest。
- 上传遵循官方 FTN 两阶段协议，在本机计算累计 SHA1 中间状态、MD5 与校验尾部。上传完成的 file_id 可能为空，通过目录查询与下载字节校验确认完成。
- 每个设备只保留最新两份已校验 DB；仅回收本设备更早的代次，其他设备和未知文件不清理。新文件完成上传并下载字节校验后才回收旧文件，回收接口明确使用 `delete_completely=false`。无未知文件时稳定总量最多为设备数×2+1；首次只读取协议 DB 和每台设备的最新 DB，后续按内容哈希使用本地缓存。失效设备的最后两份不自动按时间删除。
- 本地待发送记录保存代次、文件名和原始 DB 字节，失败及响应丢失后复用同一代次。退出取消等待，下一次先补发待发送 DB，再合并后续修改。清理失败不回滚已完成同步，界面显示待重试原因，`.cloud/state.json` 保存待清理清单，后续同步重新核对精确文件身份再重试。
- 单个远端 DB 最大 32MiB，解压载荷最大 128MiB，最多 200,000 项记录、每项 64 个并发版本和 1,000 个设备上下文；超限保留本地并提示。删除标记及因果上下文不随历史文件回收而丢弃。
- 所有设备升级并停止旧版同步后，第一次同步迁移 v1 的 `.snapshot.gz` 与 `commit-*.json`：验证账号、哈希、完整提交图与共同祖先，合并全部分支；原字节备份到账号工作区 `.cloud/legacy-backup/<标识>/Data|Sync`，新增目录不改历史 Backup。发布并校验协议 DB、完成本地应用后，只回收来源清单内身份和哈希一致的旧文件。迁移中断可从已发布协议及持久状态恢复。没有可靠旧基线的本地差异保留为冲突。
- 并发产生不同协议 DB、缺失协议 DB，或出现来源清单以外的旧提交时停止同步/清理，提示全部设备升级，保留数据；不同时维护两套可写协议。清理不是跨设备锁，升级前须停止旧客户端。
- 同一设备身份的同一代次存在不同 DB 时拒绝选取和清理，不能按文件名/哈希字典序选择胜者；直接复制同步缓存到另一台设备不等同于建立新设备。旧离线副本不能覆盖因果上更新的已删除容器最后有效内容。
- `ConnectionCheck-*` 下的 `connection-check.json` 是 `Verify-Weiyun.ps1` 的合成上传/下载连通性探针；`CloudCheck-*` 是隔离验证空间。正式同步不读取这些文件。用户已删除此前探针，本轮不重建、不批量删除测试目录或未知文件。

### 合并与落盘

- 数据库格式 v5 增加稳定笔记 GUID、逻辑名称、任务/模块/历史删除标记，产品版本独立。旧格式先备份；导入旧库只升级副本。手动覆盖保留目标笔记同步身份，并为被替换掉的记录补删除标记；普通文件导入按 BookId 合并；只有明确的“保留双方为独立副本”操作产生新身份。
- 每本笔记通过 BookSettings 的 IsHidden 字符串 true/false 保存隐藏状态，缺失默认可见；该设置沿用逐记录同步及冲突处理，数据库格式保持 v5。界面展示开关仅限会话，启动及账号切换默认关闭；隐藏库仍完整参与同步、导入、导出和备份。同步修改隐藏设置会重新筛选笔记并按既有编辑保护切换当前笔记。
- 快照覆盖完整笔记、模块、任务、富文本、状态历史、回收站和笔记内设置，排除全局设置、窗口位置、Backup 和凭证。每项记录包含一个版本或多个未决版本；删除是明确标记，不以“没有查询到”代替永久删除。
- v2 按记录保存“设备GUID＋递增计数”版本点和已观察上下文，合并只淘汰已经被后续修改观察并替代的版本；不同任务自动合并，并发内容、删除与修改并列保留，不依赖已经回收的历史 DB。Revision、UpdatedAt、EditedAt 不作为冲突胜负依据。删除容器保留最后有效内容，在并发依赖仍存在时显示为容器冲突，防止失效引用。v1 迁移阶段继续使用最近共同祖先的三方合并。
- 冲突持久保留，可选本地或云端版本、为笔记/模块/任务建立独立副本、或稍后处理。设置和历史等单值记录选一个版本。选择删除模块时关联任务转未分配；选择永久删除任务时删除相关历史并保留标记。
- 应用云端数据前在工作区存储锁内重新比较本地完整快照，变化则重新同步。所有改动库先备份和验证暂存库，持久化 apply-journal 后替换；失败或重启按恢复日志回滚。恢复只接受安全文件名与匹配的笔记身份，不清理用户历史 Backup。
- 正在编辑、草稿未提交、导航或本地修改进行中时暂缓应用。界面更新优先使用变更集：无变化不刷新；有变化只更新受影响笔记、模块、记录和必要分页窗口，保留对象、筛选、滚动、草稿及焦点。撤回传递实际记录 ID；普通刷新、撤回和后台同步不使用全屏遮罩，也不调用全局外观刷新。只有启动初始化和首次云内容初始化复用加载界面，显示阶段及已知文件数量；未知总量使用不定进度，云加载支持取消，成功/失败/取消均收起。编辑暂缓后等待结束信号，不反复联网。

### 调度与交付

- 默认自动：启动检查、5 分钟周期，提供 5、10、15、20、25、30、60 分钟七档周期；旧设置中的 2、3、8 分钟回退为 5 分钟，60 分钟在标题显示为“1 小时”，设置仍保存整数分钟。修改、撤回、导入、冲突处理和结束编辑只记录变化，不触发 5 秒同步或提前请求；网络恢复不缩短周期。完成、失败及暂缓后重新等待所选周期，且不早于服务端冷却期限。用户可关闭自动并手动操作，每轮只有一个网络操作。
- 修改代次隔离旧同步完成；同步期间新增修改和撤回等待手动或正常周期，已发送和待发送的不可变提交不改写，后续提交以恢复字段及删除标记补偿。
- 每次先在工作区锁内捕获全部逻辑记录，SHA-256 比较 `.cloud/checkpoints/local-<哈希>.json` 中上次成功同步的版本，排除 SQLite 物理布局、Revision/UpdatedAt、本机外观与日志。损坏／缺失基线强制完整验证；失败、取消、暂缓不推进基线。待上传因果版本、导入冲突和清理事项不能被跳过。
- 无本地变化时，双向／下载／周期同步仍列必要目录，比较协议和各设备最新 DB 的身份、名称、大小及文件名 SHA-256；一致返回“已检查，无变化”，不下载、上传、合并或刷新界面。上传指令无变化且无待办时零请求。两级哈希分别比较本地逻辑快照与云 DB，不交叉比较不同载荷；缓存沿用云端文件名，下载校验字节，删除前核对身份。
- 同步时间继续持久保存；上次成功同步的耗时（秒、两位小数）仅保存在内存，覆盖上传/下载/本地应用。失败、取消、编辑暂缓保留上次成功耗时；重启、切换账号和退出登录后清空。时间与耗时同行显示为 `上次同步：yyyy-MM-dd HH:mm:ss | 耗时: 1.23 秒`，没有耗时同时隐藏分隔符。
- 117401 是每日调用配额耗尽，不是空间不足；暂停至服务端恢复时间，未提供时默认北京时间次日零点后少量随机延迟。HTTP 429 遵守 Retry-After，未提供时 60 秒指数退避到 15 分钟，不即时重试。117407 是凭证禁用，停止自动请求，重新授权或联系官方处理。限制按账号持久保存，手动和重启不绕过；5xx 最多三次有限重试。本地写入不等待网络。
- 正式 Release 在程序目录 Log 记录生命周期、异常及脱敏同步链路，单文件 10 MiB、保留七天，账号面板可打开日志。HTTP 200 内的协议／业务错误也完整记录，SSE 收到匹配结果后结束读取，不等连接关闭。日志不包含凭证、Cookie、签名地址、笔记正文及上传载荷，不写 C 盘日志目录。
- 扫码授权不是无限容量或永久免费承诺。微云协议约束未经腾讯授权的第三方程序；本实现使用正式公开注册和授权接口，目前未查到针对该方式的明确禁用条款，也未取得独立 WPF 产品公开分发的专门说明。按用户确认继续本地实现；公开 Release 前核对当时适用平台规则。
- 交付目标包含 GitHub Release；本轮仅生成本地 Build。当前轮次不隐含 Git 提交、推送、标签或远程 Release 授权。
