# 颜色粘贴与末行编辑验收（2026-09-25）

## 实现

- 三个导出颜色输入框把原生右键菜单视为编辑过程。失焦校验延后到输入事件结束，菜单关闭后重查焦点；回调检查版本、输入值与笔记仓库，避免过期校验。合法值继续预览，真正离开时保留原来的格式校验与保存。
- 任务编辑开始时清除旧分页意图，把列表滚到底的目标换成有限偏移。保留 180ms 高度展开动画，卡片在展开和首次聚焦期间阻止自动移入视口，恢复自然尺寸后聚焦一次、按需定位一次。
- 主动滚轮或操作滚动条取消该次自动定位；编辑器内方向键不再作为列表分页意图。取消或卸载会使尚未执行的展开回调失效。
- 不改变数据库格式、导出颜色格式或公开接口。

## 专项入口

使用新建的独立空数据目录启动编译后的 ToDoList.exe：

```powershell
ToDoList.exe --data-dir <独立空目录> --ui-revision --color-paste
ToDoList.exe --data-dir <另一独立空目录> --ui-revision --edit-scroll
```

结果分别写入数据目录父目录的 `color-paste.json`、`edit-scroll.json`，必须同时检查 `Completed=true` 和 `Passed=true`。两项专项会使用实际窗口；颜色专项会写入测试剪贴板内容，鼠标专项只有在测试窗口处于前台时才发送输入。

## 证据与边界

- 颜色专项 22 项通过，见 `artifacts/color-paste-20260925-145559/color-paste.json`。三个字段均验证原生右键菜单、菜单粘贴命令、Ctrl+V、空值取消菜单、真正离开时非法值提示、纠正后保存以及重开笔记。
- 240 条任务的真实鼠标双击底部编辑专项 96 项通过，见 `artifacts/edit-scroll-pointer-20260925-145946/edit-scroll.json`。覆盖两种窗口宽度、两种字号、长短文本和减少动态效果，共 16 组。记录逐帧高度、滚动偏移、编辑区在视口内的位置，以及焦点与自动滚动请求次数。每组观察三秒，检查最后一秒稳定，同时验证输入保存、模块选择保存、立即取消和主动滚动。
- 既有 `--ui-revision` 回归 89 项通过，见 `artifacts/revision-color-scroll-20260925-150158/revision.json`，包含原展开高度检查、编辑时间、颜色预览、多选、报告与退出行为。本轮没有重新执行其他独立退出参数及所有历史专项。
- 初次修复前采样发现部分场景在 600ms 后仍有偏移变化，但虚拟化的总高度估算也会改变偏移，不能据此宣称已稳定复现用户描述的无限抖动。验收同时检查视口内位置和实际交互；不能仅凭高度范围或编译通过判定。
- 中间鼠标回归的后续双击曾被保存提示遮挡；专项等待提示正常消失后再点击，保留真实命中检查。没有为测试关闭应用提示。
- 不覆盖所有 Windows、DPI、输入法和窗口组合。历史任务验收文档保留原始记录，不能视为本轮全部重新执行。
