# 微云接入验证

## 职责

验证“微信登录微云、用户无需复制 Token、应用直连用户空间”的真实接入条件。这里记录原生实现前的接入验证工具；后续 WPF 登录、账号工作区、自动同步和冲突界面已接入，完整契约与验证见 [云同步](云同步.md)。

方案指定的云端结构是 `ToDoList/Data` 与 `ToDoList/Sync`。传输验证只在 `ToDoList/ConnectionCheck-<随机标识>` 内创建合成数据；不上传用户笔记，不修改用户本地 Data、Backup，也不删除微云中的文件。

## 入口

[Verify-Weiyun.ps1](../tools/Verify-Weiyun.ps1) 使用 PowerShell 7 和原生 .NET HTTP、PKCE、哈希及 Windows DPAPI。这个环境要求仅用于开发验证；不意味着最终 WPF 用户需要安装 PowerShell、Python、Node、MCP 或 AI 工具。

```powershell
# 首次验证：输出官方授权地址，操作者打开并亲自微信扫码和确认授权。
pwsh -NoProfile -File tools/Verify-Weiyun.ps1

# 复用本 Windows 用户已完成的验证授权，不重新扫码。
pwsh -NoProfile -File tools/Verify-Weiyun.ps1 -ReuseSession

# 必须使用另一个微信微云账号；复用同一账号会判为失败。
pwsh -NoProfile -File tools/Verify-Weiyun.ps1 -SecondAccount
```

授权回调最多等待五分钟；不自动操作扫码、协议勾选或权限确认。工具输出 `AUTH_URL` 后可在浏览器中打开。验证文件与加密凭证仅保存在不提交的 `artifacts/weiyun-probe`。

官方入口与协议依据：

- [微云官方接入页](https://www.weiyun.com/act/openclaw)。
- [OAuth 授权元数据](https://www.weiyun.com/.well-known/oauth-authorization-server)。
- [MCP 资源权限元数据](https://www.weiyun.com/api/v3/mcpserver/.well-known/oauth-protected-resource)。
- [腾讯微云许可及服务协议](https://docs.qq.com/doc/p/41c2260c452703e0d5dde8f2159d0b565f511b68)。

## 契约

- 固定官方 issuer、授权、注册和 token 地址；只接受 S256 PKCE 与无需密钥的桌面客户端。先绑定本机 IPv4 回调监听，再注册客户端；检查回调路径、方法和随机 state，取消与超时均失败。
- 访问凭证和刷新凭证只保存为 Windows 当前用户 DPAPI 加密文件。标准输出、报告与 Git 不保存凭证、授权 code、下载凭证 Cookie 或真实目录列表。
- 通过正式 MCP `weiyun.list` 查询授权目录；按页查询，遇到目录身份改变或无进度拒绝继续。多份同名 ToDoList 目录不能擅自选取。
- 创建 ToDoList 时若服务器改名，停止而不是把文件上传到另一个目录。测试子目录必须是本次创建的随机目录，所有上传和下载使用明确的目录 ID。
- 测试内容小于 128 字节，采用该长度下可确定的 SHA1 内部状态，不代表已实现任意大小存档的分块哈希与断点续传。
- 上传完成后按唯一文件名查询 file_id，再下载与上传字节逐一比较。下载使用独立 HTTP 客户端，不向下载主机发送 OAuth bearer，不跟随下载重定向。
- 刷新凭证后重新查询空间，检查授权目录是否一致。报告只保存空间指纹；第二账号测试要求指纹不同。
- `TRANSPORT_PASSED` 和 JSON 中的 `passed` 只表示本次账号授权与传输验证通过；第二账号另外以不同空间判定。`implementationGatePassed` 保留为 false，不代表公开分发条件或正式同步功能验收通过；用户随后明确确认使用正式接口继续实现，并在登录界面与 README 加入授权须知，目标包含后续 Release。
- 微云服务协议 8.1.2(6) 对未经腾讯开发、授权的第三方程序接入及传播有约束。公开 OAuth 注册已通过，但尚未确认这是否足以满足 ToDoList 公开分发的授权条件；不能把用户扫码授权等同于腾讯对产品分发的授权，也不能据此断言官方 OAuth 接入被禁止。
