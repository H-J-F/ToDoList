# 撤回、同步计时与周期滑块验收

## 职责

记录本轮任务/模块撤回、同步并发、运行会话耗时及周期滑块的真实验证入口与覆盖边界。全部测试使用隔离数据，不操作用户 Data、Backup 或正式微云空间。

## 入口

- 存储与同步：[LocalUndo](../src/ToDoList.Storage/LocalUndo.cs)、[UndoTests](../tests/ToDoList.Tests/UndoTests.cs)、[CloudUndoTests](../tests/ToDoList.Tests/CloudUndoTests.cs)。
- 实际 WPF：[UndoChecks](../src/ToDoList.App/MainWindow.UndoChecks.cs)。从工程根目录启动 `ToDoList.exe --data-dir <工程绝对路径>/artifacts/undo-ui/<新标识>/Data --ui-revision --undo-checks`；首次要求空工作区。
- 进程重启：复用该数据目录，增加 `--undo-restart`。首次输出 `ui-results/result.json`，重启输出 `ui-results/restart.json`。检查 Completed、Passed、Failure 及外部进程退出。
- `--undo-routed-input` 仅供无法取得前台时的 WPF 路由事件检查，不能代替真实 OS 输入。合成云服务在本机内存中运行，不发起网络请求；隔离测试的同步状态使用游客身份，不污染凭证或账号配置。

## 契约

4.5 秒内只撤回最近一次任务或模块操作；进度结束再等 0.5 秒淡出，替换消息时计时和动画重启。同步开始/完成不结束机会，进入同步后撤回重新触发 5 秒自动同步；旧同步完成不清除新代次。撤回使用原子行恢复和必要删除标记，相关记录冲突时不覆盖。耗时不持久化；滑块使用方块与九项独立对齐文字。
