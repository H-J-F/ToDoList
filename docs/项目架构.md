# ToDoList 项目架构

## 职责

本地优先的 .NET 10 Windows WPF 待办应用。`ToDoList.App` 承担窗口、富文本编辑、主题、托盘、报告导出；`ToDoList.Core` 定义领域模型、内容验证与报告筛选；`ToDoList.Storage` 管理笔记文件、SQLite 事务、迁移、备份和合并。App 引用 Core 与 Storage，Storage 使用 Core。

## 契约

- 外观以 `ThemeId` 为唯一生效字段，`SettingsVersion` 为 3；旧 `Mode` 仅用于迁移，旧 `AccentPreset` / `Palette` 不再控制外观。未知主题回退经典浅色；跟随系统只解析为经典浅／深色，候选固定明暗。自动正文、任务状态与控件画笔一起切换；显式富文本颜色和导出颜色独立保留，数据库格式不变。

- 主题选择包含跟随系统、两个经典主题与八套候选；选择框统一 164 DIP。主题专用 Popup 固定行高、整行滚动，仅淡入，不进行纵向位移；鼠标悬停不改变布局。

- 凭证、活动账号及资料缓存位于程序根目录 Auth，登录浏览器缓存位于 Auth/Browser；Windows DPAPI 保护保持不变。正常升级迁移当前 Data 对应的旧用户目录缓存，成功验证后清理来源；隔离 --data-dir 使用指定 Data/Auth。活动账号本地加载先于授权检查，过期、损坏凭证和云初始化失败不阻止已确认账号的本地使用。
- 笔记隐藏使用 BookSettings.IsHidden，缺失默认可见，随账号同步，数据库仍为 v5。BookInfo 包含 IsHidden 与仅用于展示的 DisplayTitle；MainViewModel.Books 保留完整集合，VisibleBooks 用于导航筛选。菜单可隐藏／取消隐藏、展示隐藏笔记；展示开关在启动和切换账号时默认关闭。隐藏不影响完整存储、备份与云同步；全部隐藏时显示恢复入口。
- 数据默认位于程序同级 Data。每本笔记一个数据库；导入、导出与备份通过存储层完成，不通过直接覆盖运行中的数据库升级。
- 数据库当前格式为 v5，v1/v2/v3/v4 升级前备份；新增 SyncIdentity 与 SyncTombstones，导入旧库只升级暂存副本。格式版本和产品版本独立。
- 微云通过原生 .NET OAuth PKCE 与官方 MCP 接口直连；游客与每个账号工作区独立。云协议 v2 在 ToDoList/Data 保存每台设备最新两份不可变 SQLite DB，Sync 保存唯一协议初始化 DB；完整数据和逐记录因果上下文支持离线并发合并，冲突保留双方。上传并校验后回收本设备多余 DB，失败持久记录并重试；旧格式验证、备份后迁移，所有设备须升级。DPAPI 保护凭证，本机外观不进入云存档。详细契约与验证见 [云同步](云同步.md)。
- 左侧账号与设置使用相同的 40 DIP 行高、20 DIP 图标区域、12 DIP 水平内边距和 10 DIP 图文间距；文字与图标中心对齐。未登录显示灰色 PersonCircle20 和“未登录”；已授权显示经过空间校验的缓存昵称与圆形头像，缺失资料回退“已授权”和默认图标。账号与设置面板互斥，可重复点击、外部点击、关闭按钮或 Escape 收起，隐藏窗口时结束动画并收起。
- 微云登录使用 WPF UI FluentWindow 和微软 WebView2 1.0.4258.31，授权与 token 交换仍由原生 PKCE 层执行。每次登录使用隔离的 InPrivate 会话；官方页面资料与 token 空间匹配后按工作区／账号 DPAPI 缓存，资料不参与账号身份与云快照。完成关闭登录窗口，失败可主动选系统浏览器。当前用户级 todolist-desktop://activate 仅激活单实例，不携带授权参数；隔离验证不修改用户协议关联。真实扫码与资料取得须独立验收，详见云同步文档。
- 本地笔记复制到账号通过 BookLibrary.CopyBookAsync 使用完整数据库快照，保留原标题、内容与历史，不截断或追加“本地副本”。保持 BookId、任务及历史身份；同 ID 合并，不同 ID 同名保持独立，仅文件名必要时避重。同一记录不同版本持久保留为冲突，不按修改时间覆盖。
- 待办笔记以 BookId GUID 识别，名称与文件路径不是身份；导航和草稿归属按 ID 记忆，旧名称设置首次成功匹配后迁移。重命名只修改展示标题，ID、文件路径不变。
- 模块右键“迁移到其他笔记”包含全部任务、回收站及状态历史；同名时明确选择合并或改名。保留任务／历史 ID，两本库统一提交和恢复。源端写删除标记，迁回时允许替换目标删除标记并清除它；目标有效记录内容冲突或相关同步冲突仍阻止迁移。
- 授权有效 14 天，Token 刷新不续期。同步由手动或自动周期触发，默认 5 分钟，5、10、15、20、25、30、60 分钟七档可选；旧设置中的 2、3、8 分钟回退为 5 分钟。修改、撤回和结束编辑不提前同步，失败及暂缓等下个周期。先比较逻辑快照 SHA-256，成功后保存哈希命名基线；无本地变化仍检查云端最新 DB 身份及哈希，无两端变化不上传下载或刷新。117401／HTTP 429／117407 分别处理每日额度、临时限流和凭证禁用，限制持久保存，手动与重启不绕过。
- 界面更新优先按需更新：使用实际变更集按笔记／模块／记录 ID 更新，保留对象、分页窗口、筛选、滚动锚点和输入焦点；无变化不刷新集合。撤回、日常同步和普通刷新不显示全屏遮罩；通用 IsBusy 只用于操作互斥。全屏加载仅用于启动与首次云内容初始化，已知数量显示真实进度，未知时不定进度；云初始化可取消，失败或取消均收起。编辑和草稿暂缓云应用，不调用全局外观刷新。
- 已有待办真正失焦自动保存退出，切换软件和最小化也适用；工具栏、模块选择、颜色／表情 Popup 和链接对话框属于编辑作用域。失败保留编辑并阻止导航；取消和 Escape 放弃修改。底部提交先恢复可用状态再设置实际键盘焦点，输入法组合期间 Enter 不提交。
- 每个 Data 工作区增加目录级存储锁，笔记查询和写入与多库同步应用互斥。云应用先备份和完整校验暂存库，再持久化恢复日志后替换；中断或失败按日志恢复旧库。数据写入后通知同步调度，查询不触发脏标记。
- `EditedAt` 只表示内容（含格式）或归属模块的实际修改，状态切换、删除、恢复不改变它；`UpdatedAt` 用于整条任务合并比较。没有历史修改时间就不显示。
- 全局单实例；托盘使用 WPF-UI.Tray 4.3.0 的 NotifyIcon，菜单沿用 WPF UI 主题。关闭窗口隐藏到托盘；退出获准后先关闭弹窗、释放输入捕获、注销托盘并销毁注册时创建的消息源，再关闭主窗口和显式 Shutdown。取消或保存失败保留窗口与托盘，退出过程中忽略新的激活。隐藏窗口前也结束弹出控件的输入捕获；不禁用全局触笔／触摸支持。
- 设置同步独立于笔记导航。主题、字号、密度、动画分别按变化更新；下拉选择完成后合并应用并保存，失败恢复上一份有效外观。设置弹窗中的点击属于设置内部操作，不能触发外部点击关闭。中断动画必须恢复终态并完成等待任务。
- 切换笔记先准备设置、模块与首批任务，成功后同一 UI 调度中提交，失败保留原笔记与 LastBook（BookId）。切换不使用全工作区遮罩；标准模式将旧内容快照在新内容上淡出 150ms，减少动态效果时直接更新。窗口背景与标题栏不参与淡化。
- 列表每次加载 200 条，缓存最多 2,000 条／32MiB；后台查询取消旧请求并隔离迟到结果。分页、筛选和报告不能以当前可见列表代替完整数据库结果。
- 测试和诊断必须用 `--data-dir` 指向独立目录。不能将用户 Data 纳入索引、发布或验收样本。
- 导出颜色输入在真正离开输入框后校验保存；右键菜单打开和关闭属于输入过程，不提交临时空值。合法颜色仍实时预览。
- 任务编辑保留展开动画；展开及首次聚焦期间抑制卡片的自动移入视口请求，布局完成后至多调整一次可见区域。用户滚轮或拖动滚动条取消本次自动定位；编辑器内方向键不作为列表分页意图。

- 任务与模块写入通过 TaskRepository 的可选连接级撤回记录，在原事务内捕获本次受影响行；LocalUndo 在内存保存一次性凭据。恢复校验相关记录、保留无关变更并递增任务 Revision/UpdatedAt；取消新增记录和状态历史写同步删除标记，数据库格式仍为 v5。失败和无实际变化不生成凭据。
- 右下角 OperationToast 只允许撤回最近一次任务或模块修改（任务与新模块组合新增为一次）。4.5 秒进度从满到空，到期禁用按钮，另等 0.5 秒再淡出；新修改立即替换内容并重计，重复文字也有效。笔记、跨笔记迁移、导入、永久删除、设置和云端操作不提供撤回；切换笔记/账号、隐藏窗口及关闭气泡释放机会。点击气泡不触发编辑失焦保存。
- 同步开始与完成保留原撤回期限；撤回只标记本地修改，等待手动或正常周期。修改代次隔离旧同步完成，待发送提交保留并以后续提交补偿。IsBusy 不禁用整页控件；模块集合差量协调，正文与状态分别通知，无正文变化不重建富文本。
- 整本笔记及报告默认导出名取当前 Title，经 Windows 文件名处理；Name、BookId 和源路径不因展示改名改变。正式 Release 使用 Core RuntimeLog 在程序目录 Log 写脱敏日志，单文件 10 MiB、保留七天；日志失败不阻断数据保存。
- 账号面板同行显示上次同步时间与 ` | 耗时: X.XX 秒`，没有耗时时隐藏分隔符；耗时由 Stopwatch 统计，失败、取消和编辑暂缓不更新，仅保存在运行会话中，重启、切换账号及退出登录清空。周期滑块使用 14×14 DIP 方块，无外围边框和聚焦框，仍支持键盘调整；七项独立数值以实际 Handle 中心范围对齐刻度，范围、刻度和标签位置从周期列表派生；60 分钟选中时标题显示“同步周期：1 小时”。
- OperationToast 标准展示为 180ms 从右侧 48 DIP 飞入并淡入，关闭/超时向右飞出并淡出；减少动态效果仅 90ms 淡入淡出。快速替换隔离旧动画回调；关闭开始立即释放撤回机会，隐藏窗口及卸载立即清理。

## 验证

性能专项 `--data-dir <工程绝对路径>/artifacts/<独立标识>/Data --ui-perf` 在启动时校验隔离路径并使用独立实例。附加 `--memory-checks` 仅接受空工作区，生成一万条合成任务，采集分页／筛选／编辑／切换及五分钟静置样本，使用拦截全部请求的合成登录页检查浏览器子进程退出。结果写入 Data 同层 `memory-results.json`；不强制 GC 或裁剪工作集，不接触真实账号。测量定义、结果与边界见 [同步周期与内存分析](VALIDATION-INTERVAL-MEMORY.md)。

凭证目录、离线账号与笔记隐藏的本轮验证见 [凭证与隐藏验收](VALIDATION-CREDENTIALS-HIDDEN.md)。

本轮请求、日志和导出命名回归及 WPF 逐帧结果见 [同步与日志修复验收](VALIDATION-SYNC-LOG.md)。

主题专项使用 `--data-dir <独立空目录> --ui-themes`；复用该专项数据加 `--theme-restart` 验证进程重启。生成主界面及包含独立 Popup 的 WPF 渲染图、总览、HTML 画廊和 JSON 断言结果。详细契约及验证边界见 [主题与预览](主题与预览.md)。

`dotnet build ToDoList.sln -c Release` 与 `dotnet test tests/ToDoList.Tests -c Release` 覆盖编译与存储/规则测试；`Build.bat` 统一执行。UI 生命周期、动画和富文本变化按实际影响运行相应 UI 专项。已有复现入口、证据及已知验证限制见 [任务修改验收](VALIDATION-TASK-REVISION.md)、[报告回归](VALIDATION-REPORTS.md)。历史报告不代表当前包已重新运行所有 UI 专项。

维护流程见 [项目闭环](../.codex/项目闭环文档.md)，用户操作见 [README](../README.md)。

颜色粘贴与底部编辑专项入口为 `--data-dir <独立空目录> --ui-revision --color-paste` 和 `--data-dir <独立空目录> --ui-revision --edit-scroll`。检查输出 JSON 的 `Completed` 和 `Passed`；证据与限制见 [本轮交互验收](VALIDATION-COLOR-EDIT-SCROLL.md)。

综合专项运行 `python -X utf8 tools/Verify-Lifecycle.py <ToDoList.exe>`，外部检查窗口关闭后 5 秒内进程结束，覆盖两种动画模式、隐藏／显示窗口、辅助隐藏窗口、未保存内容、设置／笔记操作及重启。托盘场景通过 Shell_NotifyIconGetRect 定位本实例图标，实际鼠标右键和点击菜单；辅助窗口场景保留程序性菜单事件检查。设置专项包含真实鼠标／键盘、落盘失败恢复、慢加载与逐帧切换记录。验收期间不能同时操作鼠标键盘。生命周期隔离标识用于注册和激活，详见 [2.3.9 综合验收](VALIDATION-2.3.9.md)；[上一轮退出记录](VALIDATION-TRAY-EXIT.md)保留其历史覆盖边界。

撤回、同步计时和方块周期滑块的专项入口及覆盖边界见 [本轮撤回验收](VALIDATION-UNDO-SYNC.md)。

云 DB 精简、实际删除权限、模块迁回与进度/动画验证见 [DB 与刷新验收](VALIDATION-CLOUD-DB.md)。
