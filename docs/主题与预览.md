## 入口

- [ThemeCatalog](../src/ToDoList.Core/ThemeCatalog.cs)：平台无关主题定义、对比度与设置规范化。
- [ThemeService](../src/ToDoList.App/Services/ThemeService.cs)：解析跟随系统、覆盖主题资源与控件画笔，通知正文刷新。
- [ThemeBrushAliases](../src/ToDoList.App/Services/ThemeBrushAliases.cs)：基于 WPF UI 4.3.0 的显式颜色／画笔映射；依赖升级时核对资源名。
- [UiThemePreview](../src/ToDoList.App/Services/UiThemePreview.cs)：真实 WPF 窗口专项、弹出窗口捕获、八套总览和本地画廊。
- [UiThemeDropdownChecks](../src/ToDoList.App/Services/UiThemeDropdownChecks.cs)：真实鼠标移入、滚轮和键盘导航，记录弹层与选项坐标及滚动偏移。
- [ThemeTests](../tests/ToDoList.Tests/ThemeTests.cs)：主题对比度、迁移、无效主题与系统解析测试。

## 契约

- 设置面板只有一个“主题”选择框，显示名称与三色缩略色块。`system` 解析为 `classic-light` / `classic-dark`；八套候选不因系统设置改变明暗。
- 设置下拉框统一使用应用维护的稳定模板，宽 164 DIP、固定 40 DIP 行高、按完整选项滚动，弹层最高 280 DIP；主题项额外显示色块。普通模式只淡入，减少动画时直接显示；悬停只改颜色，不调整布局，也不在运行时替换库模板的变换对象。
- `ThemeId` 是外观唯一生效设置，设置格式升级为 3。旧 `Mode` 在首次迁移时保留明暗意图；旧强调色字段仅兼容读取。无效主题和现代配置中缺失的主题回退经典浅色。
- 重置外观使用经典浅色，并沿用原来的字号、间距、动画重置行为。产品版本和数据库格式版本的规则不变。
- 切换主题不重建编辑文档；正文自动色、光标、文本选择色随主题更新，显式富文本色与导出标记颜色保留。已完成文字使用专用前景，避免整体透明度导致低对比度。
- 配色、字号、密度与动画采用独立的增量更新；切换减少动态效果不重新替换主题字典。设置选择事件结束后统一应用和保存，连续选择保留各字段最后值，保存失败回滚外观与选择值。弹窗选项点击不会关闭设置面板。
- 设置面板动画可被安全中断：模式切换、卸载或新动画会完成旧等待并恢复终态。笔记切换仅对内容区执行 150ms 交叉淡化，减少动态效果时直接更新；托盘由 WPF-UI.Tray 4.3.0 驱动，菜单继续使用当前主题资源。
- 正文、辅助文字、链接、状态文字和主按钮文字的预设搭配达到 4.5:1；输入边界达到 3:1。装饰分隔线及禁用状态不适用该阈值；用户指定的富文本／导出颜色不自动改写。
- 同时覆盖颜色与静态画笔别名，包括背景、菜单、弹窗、日历、提示条、按钮和选中状态；主题选择框使用专用稳定模板，其他控件保留库模板与交互。

## 验证

```powershell
dotnet test tests/ToDoList.Tests -c Release --filter FullyQualifiedName~ThemeTests
ToDoList.exe --data-dir <独立空目录> --ui-themes
ToDoList.exe --data-dir <同一专项目录> --ui-themes --theme-restart
```

专项要求显式 `--data-dir`，首次运行拒绝含笔记的目录，使用独立单实例标识，结束退出。不会终止或激活用户已有程序。每次重新生成整套预览应使用新的空目录。

数据目录的父目录输出 `theme-results.json` / `restart-results.json`；必须分别检查 `Completed` 与 `Passed`。界面断言覆盖主题选择、控件实际画笔、任务状态、打开菜单时换色、富文本编辑内容与选区、重置、保存、重启，以及十套固定主题 × 四档字号 × 两种窗口尺寸的布局。

专项还通过真实 OS 鼠标输入检查首项、中间项、末项选中时，立即及延迟移入、多次移入移出后的坐标稳定，普通与减少动画模式均覆盖；检查滚轮、Home、End、方向键、Enter、Esc，并输出 `dropdown-observations.json`。

每套候选输出主界面、设置下拉框、任务菜单、输入弹窗、日历、编辑与最小窗口 PNG，另有 `overview.png` 和 `index.html`。这是运行中 WPF 的视觉树渲染，独立 Popup HWND 按实际屏幕位置合成；不是 HTML 模拟图，也不是物理显示器 DPI 切换测试。自动测试不能替代用户审美评审。

本轮验证见 [主题下拉框与蓝色候选验收](VALIDATION-THEME-BLUE.md)，原六套记录见 [初次主题验收](VALIDATION-THEMES.md)。交付过程仍须主动执行根目录 `Build.bat`，只发布到本地 Build。

设置与笔记切换的后续验证见 [2.3.9 综合验收](VALIDATION-2.3.9.md)。入口为 `--data-dir <独立空目录> --ui-revision --settings-navigation`，复用同目录增加 `--settings-restart` 检查重启持久化；`--tray-native` 补实际托盘退出。专项输出 settings-navigation.json、选择事件轨迹及切换帧 PNG。
